# Evidence States

- **Official** — authoritative public publication.
- **Secondary** — independent context or corroboration.
- **Reported Development** — credible reporting not established as final policy.
- **Analysis** — Bridge Node 7 interpretation.
- **Unknown** — not adequately established.
- **Superseded** — historical state replaced by a newer record.

Status and evidence-state values are observations within the dated reviewed record. They are not representations of continuously live state.
