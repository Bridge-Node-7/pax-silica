# Time-to-Switch

**State:** BN7 Analysis
**Verified context:** 2026-08-15

Time-to-Switch (TTS) is an analytical measure for the elapsed time from loss of an incumbent source to qualified production through an alternate pathway.

A useful decomposition is:

Detection + Decision + Contracting + Tooling + Qualification + Regulatory + Logistics + Production Ramp.

## Reality shadow

If prequalification materially improves resilience, an alternate pathway prepared before disruption should produce a measurably lower Time-to-Switch than an equivalent pathway discovered and qualified only after disruption.
